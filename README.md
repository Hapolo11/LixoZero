# LixoZero

Assistente doméstico de reciclagem: classifica cada resíduo (plástico, papel, vidro,
orgânico, perigoso) e indica o destino correto mais próximo — ecopontos e cooperativas de
catadores.

## Missão

Reduzir o volume de resíduos enviados a lixões e aterros sanitários, educando a população
sobre separação correta, compostagem doméstica e logística reversa de recicláveis.
